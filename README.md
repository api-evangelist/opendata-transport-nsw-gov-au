The Transport for NSW Open Data Hub (opendata.transport.nsw.gov.au) is the central location for all Transport for NSW open data, established in April 2016 at the Future Transport summit to replace the Transport Data Exchange (TDX) program. It hosts over 200 datasets with more than 1000 resources (APIs, downloadable files, interactive maps and insights), including GTFS and GTFS-realtime public transport feeds and Live Traffic NSW data, used by 35,700+ registered developers who have created 9000+ applications. The catalogue runs CKAN, exposing the standard CKAN Action API for dataset search and metadata, alongside a developer portal with documentation, a user guide, API status, FAQs and a community forum.

**Areas:** Open Data · CKAN · Data Catalog · DCAT · Government Data · Open Data Portal · Australia

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Transport for NSW Open Data Hub: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
